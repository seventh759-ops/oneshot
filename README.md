# 一太刀（ONE SHOT）

一撃必殺のビルドパズル（試作版）。

剣士を選び、型（パーツ）を並べて構え、1回だけ斬る。その一太刀で敵を倒せばクリア。

- 物理属性（斬撃・打撃・刺突・巫術）は剣士の武器、五行（火・水・木・金・土）は剣士の生まれ持ちと型で決まる
- 敵の体質と五行との相性で、同じ敵でも剣士ごとに解き方が変わる
- 体力ぴったりで斬ると「極」。特定の条件で極を取る「試練」で、剣士・秘伝の型・隠し幕が解放される
- 極・試練・まだ加わっていない剣士は画面に一切出さず、たまたま達成したときに初めて明かす
- 敵ごとに特性がある（糸で二の太刀を絡め取る／仕損じた五行を映し取る／仕損じるたびに守りが固くなる／挑むたびに五行が移ろう）。仕損じても敵は弱らない。「仕切り直す」で元に戻る
- 敵の体力・装甲は見せない。失敗すると剣士が手応えを曖昧な言葉で返す（`src/voice.js`）

## 遊び方

`index.html` をブラウザで開く（ビルド不要）。

## 構成

- `src/logic.js` … パーツ・ステージ定義と計算処理（DOM非依存）
- `src/main.js` … 画面と演出（条件クリア＝一閃／体力ぴったり＝極）
- `src/sound.js` … 効果音（Web Audio で合成）
- `src/monster.js` … 墨で描く異形（Canvas で生成）
- `src/style.css` … 見た目
- `tools/solve.js` … 全ビルドを剣士ごとに総当たりし、勝ち・極・試練の達成手段の数を出す（`node tools/solve.js [幕] [--list]`）
- `tools/tune.js` … 体力の候補ごとに剣士別の勝ち／極の数を出す（`node tools/tune.js <幕> [装甲] [秘伝あり=1]`）
- `tools/bundle.py` … 1ファイルにまとめる（`python3 tools/bundle.py out.html`）
