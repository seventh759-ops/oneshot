# 一撃転生（試作）

異世界に転生して授かった能力は《一撃必殺》。当てて倒しきれば必ず勝てる。
ただし攻撃できるのは一度だけ。外したら死ぬ。当てても倒しきれなかったら死ぬ。死ぬと戦いの前に戻される。

- 勝敗は数値ではなく、能力の組み合わせが敵の「当てる関門」と「倒しきる関門」を満たすかで決まる
- 死ぬと死に様が語られ、手がかりが「死に帳」に残る
- 倒した敵から能力を奪い、次の敵の攻略に使う
- 余計な能力を込めない最小の組み合わせで決めると「極」（たまたま見つける要素）
- 敵ごとに「挑戦の記録」（試した組み合わせと結果）が残る
- 確認用に、右上の「ログ」で一撃ごとの判定の中身（一撃の性質・各関門の○×・結果）を見られる。コピーして共有できる

## 遊び方

`isekai/index.html` をブラウザで開く（ビルド不要）。

## 構成

- `src/logic.js` … 能力・敵・判定（DOM非依存）
- `src/main.js` … 画面と演出
- `src/sprites.js` … 16×16 のドット絵
- `src/sound.js` … 効果音（Web Audio で合成）
- `tools/solve.js` … 能力の組み合わせを総当たりし、勝ち筋・極・死因の数を出す（`node isekai/tools/solve.js [--list]`）
- `tools/bundle.py` … 1ファイルにまとめる（`python3 isekai/tools/bundle.py out.html`）
